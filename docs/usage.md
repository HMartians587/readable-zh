# 使用 Readable ZH

安装方法见 [README](../README.md)。Codex 使用 `$readable-zh`；Claude Code 独立技能使用 `/readable-zh`，插件安装使用 `/readable-zh:readable-zh`。本文示例采用 Codex 写法；在 Claude Code 中换为对应调用名。

每次请求写明读者、用途和允许的改动范围；能从上下文判断的信息可以省略。

## 润色已有文字

```text
使用 $readable-zh 润色下面的文字，面向普通团队成员。
减少空泛和重复，保留全部独立信息、条件与计划状态。只交付成稿。

原文：……
```

默认可以调整词句和理解所需的段落组织。需要局部编辑时，指出位置：

```text
使用 $readable-zh 只修改第二段，其余段落保持原样。
保留事实、作者立场和正式语气。

原文：……
```

## 只审阅

```text
使用 $readable-zh 审阅下面的文字。
指出哪里影响理解、为什么，以及怎么改。先不要重写，也不要修改文件。

原文：……
```

## 重排正文

```text
使用 $readable-zh 重写这份说明，面向第一次使用产品的人。
可以重排普通正文与段落，保留独立信息、限制、数值和引用。
先让读者知道能做什么，再说明条件和步骤。

原文：……
```

需要摘要或删减时，另外说明长度或取舍范围。

## 技术与科研交流

可要求保留术语、参数、记录和证据强度，同时整理表述。以下材料为模拟示例：

```text
使用 $readable-zh 整理下面的模拟研究记录，写成一段发给合作者的消息。
先说当前观察，再说明设置、限制和下一步。保留全部数值，
不要补出原因，也不要把观察写成因果结论。

模拟记录（并非真实实验结果）：
同一数据划分，单个随机种子。基线准确率 81%，方案 A 为 82%。
两组都训练 10 轮。尚未做独立重复，不能据此判断差异是否稳定。
下一步计划增加随机种子，再检查差异。
```

若只需要润色，提供原稿并明确“保留原意”；需要新增解释、教学例子或外部查证时，说明允许补充的范围。

## 保持正式文体或作者声音

```text
使用 $readable-zh 润色这段报告，保持正式，不改成口语。
保留主张、来源、必要限定与技术术语。

原文：……
```

```text
使用 $readable-zh 编辑目标文章，参考我的样本文风。
只借鉴措辞、节奏和语气，不把样本中的事实或经历写进目标文章。

文风样本：……
目标文章：……
```

## 根据材料从头写

```text
使用 $readable-zh 根据下面材料写一段解释。
读者：没有相关知识的成年人。
读完需要弄明白：条件发生变化后，为什么操作也要改变。
可以使用明确的教学例子，不增加未经提供的真实事件、数据或引用。

材料：……
```

## 核对成稿

核对成稿中的具体断言是否有材料依据，原文的独立信息是否仍有对应。重点检查数值与单位、条件与例外、归因与因果、计划与完成状态，以及作者原有的判断和分寸。

已经清楚的文字可以保留原样。改动多少和篇幅长短，应由实际阅读需要决定。
