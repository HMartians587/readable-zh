# 文体与作者声音

在目标文体、作者样本或个人叙事决定修改尺度时使用。声音来自表达选择，不要求添加情绪、经历或不规则标点。

## 有写作样本时

借鉴作者的正式程度、常用词、句子节奏、对读者的称呼、直接或含蓄的态度。作者有意使用的对比、重复、破折号或四字词，不因通用模式清单而删除。只借鉴与本次用途相符的特点；不把样本的事件、观点和身份搬入目标文本。

样本不足以判断时，沿用目标文字的语域。不要把对文风的猜测写成作者特征，也不要用在每句前加“其实”“说白了”等口头禅来替代声音。

## 按用途决定尺度

| 用途 | 重点处理 | 应保留的内容 |
| --- | --- | --- |
| 日常问答、知识解释 | 回答实际问题，解释陌生概念与必要关系 | 有用例子、读者需要的重复和过渡 |
| 技术教程、故障说明 | 条件、对象、动作与可观察结果，解释何时适用 | 精确术语、参数、命令、路径、限制与状态 |
| 发布说明、工作周报 | 具体变化、进展、影响和下一步 | 计划与完成的差别、未验证反馈、真实问题 |
| 学术和专业报告 | 主张与证据、定义与范围匹配 | 正式语域、引用、必要不确定性与方法条件 |
| 邮件、团队沟通 | 收件人需要判断或执行什么，语气适合关系 | 礼貌、感谢、落款以及真实协商余地 |
| 个人评论、随笔 | 作者判断、依据与个人节奏 | 原有态度、幽默、犹豫、矛盾和第一人称 |
| 小说与文学叙事 | 事件、视角、节奏和作者选择 | 暗示、歧义、悬念、留白，不强制解释道理 |

真实人物、媒体、作家或用户样本不能成为补造经历的来源。材料只说“有人报告”时，不改成“我们发现”；只说“我认为”时，不改成普遍事实。引号中的话不润色成新的引语，必要时在引语之外解释。

## 避免替代性套路

不要用碎句、刻意句长变化、虚构小故事、俏皮话或不必要的第二人称替代原来的模版。不要把一切正式表达都改成聊天语气，也不要把所有个人态度都磨成中性说明。

朋友间的说明先让对方读清具体安排和边界，再决定理由放在哪里；保持作者原有的分寸，不把“有价值”习惯性强化为“很重要”，也不把“我愿意”改成客观评价。表达态度时可以直接，但不必另造一句口语长句来替换本来顺畅的短语。

用户仅要求评价时，给具体问题与建议。用户要求最小编辑时保留合理结构。用户允许重写时再调整全文展开；改动大小由任务决定。

## 日常表达：句子顺口，分寸不变

个人文字容易在润色后变成解释自己的报告。优先试原有主体直接接动作、判断或感受的写法，不把短句改成更长的抽象说明。以下为原创教学例子，不是换词表。

| 原句 | 可以怎样改 | 不能顺手改掉的意思 |
| --- | --- | --- |
| 我想做的尝试是，把睡前那段没安排的时间留着。 | 我想试试，把睡前那段没安排的时间留着。 | 尝试不等于决定；不能写成以后每晚都这样做 |
| 对我来说，画人物还不是现在擅长的事。 | 画人物还不是我现在擅长的事。 | 保留目前、自我判断与不擅长的对象；不能改成画不好所有东西 |
| 我开始觉得，一有空就觉得自己应该做点事，这样有点累。 | 我开始觉得，一有空就觉得自己该做点事，这样有点累。也可以保留原句。 | “觉得该做”是心理要求，不等于每次都实际去做；两处“觉得”作用不同，“开始”交代态度变化 |

“我对这件事的看法是……”若只是框架，可以直接接原有判断；若正在区分看法与事实，仍需保留归属。不要把“看法”固定换成“感受”、把“清楚”换成“容易”，也不把“有价值”加强成“很重要”。

叙述距离保持一致：朋友之间原有的“我／你”和语气可保留，不另加称呼、口头禅或亲密关系。将具体安排与适用边界放近；叙事中的反应接在它回应的事情旁边。只调整原来已有的关系，不补因果、动机和情绪。原有感受可以收尾，不必替作者归纳一个道理。
