# 含义保持与新增信息的边界

判断是否产生了新命题，不按有没有出现新词判断。源材料是本次编辑的信息范围，不等于已验证现实真实性；发现疑似事实错误时另行说明，不能靠猜测悄悄替换。

## 合法的表达变化

- 同一个事实换成更顺的说法，拆句、合句或重排，不丢失各项信息。
- 为解决实际理解问题，将上下文唯一确定的代词、量或比较对象写明。唯一性是含义条件，不是每次都展开的理由；存在多个候选对象时，不自行选定。
- 恢复原文并列事项共享的时限、条件或归因，不凭相邻位置创造共享条件。
- 为解释原文正在讨论的数量关系，写出等价计算或表述。数值、分母、单位和比较基准一致；不追加新的统计指标、效果预测或外推结论。
- 明确原文已经建立的顺序、条件或因果，不能从常识猜一个更完整的故事。

## 应撤回的变化

| 材料只说明 | 不足以支持 |
| --- | --- |
| 达到门槛时触发操作 | 操作后的确定结果、参数或完成时间 |
| 预览、提交、受理或计划 | 已保存、已批准、已生效或已完成 |
| 一部分人报告、一次观察 | 所有人、已核实事实或因果结论 |
| 某措施旨在改善某事 | 已经改善、一定改善或具体收益幅度 |
| 作者愿意、觉得或倾向于 | 更强的承诺、普遍价值判断或新的动机 |
| 一处有时间或条件限制 | 另一处没有被它约束的操作也受限制 |
| 尚无证据认定某事完成 | 已经确定某事没有完成 |
| 没收到对方的材料或回复 | 对方还没制作、没发送或没有采取行动 |

精确数字没变也可能改坏含义：阈值变目标、平均变上限、最多变保证、单位或比较分母变化，都是信息改变。一个“会”“已经”“因此”也可能产生新命题。

例如“我还没收到修好的照片，所以暂时不能确认修图已经完成”，可压成“我还没收到修好的照片，暂时无法确认修图已完成”；不能改成“修图尚未完成”。同样，“我觉得该去”与“我去了”不同，“开始接受”与一直接受不同。心理状态和态度变化属于需保护的信息，不是冗余缓冲。

## 删除也要核对

合并的是同一个意思的重复承载，不能漏掉独立事实、作者判断、否定、范围或例外。评价可以是作者立场，不因它不是客观事实就删除。背景也可能提供时间或因果条件。

原文确实只有无独立内容的预告、复述或包装时可删。无法判断某句话是否承载作者意图时，改得平实或保留，不用“去 AI 味”代替范围判断。

## 有缺口时

仅润色不补资料；可以保留概括，必要时在正文外说明具体缺口。用户明确要求讲解或扩写，才在授权范围内补充，并区分补充与原稿。写“假设”不能代替用户授权，也不能把类比写成实际机制。

## 最后检查

对修改处问两件事：删掉了原文哪一项独立信息？读者会因此新认定什么？每项具体断言都应能找到原文依据或属于明确授权的补充。找不到就还原，不把更顺畅视为通过理由。
