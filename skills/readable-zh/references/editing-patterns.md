# 按表达作用筛选修改

当正文存在套话、翻译腔或重复结构，需要具体编辑线索时使用。下表是诊断提示，不是禁词表。按文体、含义和上下文判断，没问题就保留。

| 现象 | 判断依据 | 处理方式与保留边界 |
| --- | --- | --- |
| 通用背景开场 | 删掉后，读者仍能理解主题、时间与原因 | 可以直接进入问题；背景承载趋势、条件或研究范围时保留 |
| 反复预告和总结 | 前后只是重复同一信息，没有帮助定位或记忆 | 合并重复；长文导航、操作确认和教学复述有作用时保留 |
| 空泛拔高与宣传 | 意义或评价没有材料支持，且不属于作者明确表达的立场 | 回到材料中的事实；不靠新造数字和案例替代赞美 |
| 无效对比与排比 | 对比对象无人提出，列举项反复表达同一意思 | 直接陈述或合并；纠错对比、独立功能和约束均保留 |
| 长定语、名词串和翻译腔 | 动作、对象或修饰关系难以辨认 | 写清谁做什么，按关系展开；不能猜施事者或变更技术含义 |
| 冗长动词表达 | 如“进行……的处理”可以直接表达，且含义不变 | 用准确动词，保留正在、计划、已完成、次数与范围 |
| 防御性语句 | 只是反复预防质疑，没有增加证据或界定范围 | 压缩重复；真实不确定性、必要限定与方法条件保留 |
| 聊天残留 | 正文中夹着无内容的夸奖、写作预告或继续服务提议 | 交付独立成稿时删除；邮件、客服和对话需要的礼貌正常保留 |
| 模板段落与机械节奏 | 不同段落都以相同方式展开，阻碍本次任务 | 按实际问题重排；不刻意凑不同句长、列表项数或段尾形式 |
| 装饰性格式 | 粗体、标题或符号没有帮助阅读定位 | 按需要减少；保留有用层级、列表和技术符号 |

## 中文措辞与节奏

- “的”层叠、过长前置定语影响辨认时，拆清修饰关系；不按字数一刀切。
- “进行、实现、推动、构建”等词承载实际动作时正常使用；只是包裹另一个动词时，可以用直接而准确的动词表达。
- 不能为了变化，把同一对象交替叫成多个近义词。技术名词与核心概念保持稳定。
- 被动句的施事者未知、无关或文体需要时可以保留。已知施事者且主动更清楚时才改。
- 四字词、三项列举、破折号和连接词按作用判断。区分独立信息、真实对比与纯粹凑节奏。
- 连续短句在复述同一意思时合并；每句分别推进事件或作者有意强调时保留。
- 不要求每句话都使用不同长度或开头；先让动作和关系清楚，节奏随内容自然变化。
- “可能、尚未、超过、只在、据称”等词往往承载含义。删减缓冲表达时逐项核对，不统一去掉限定。
- 无来源的“专家表示”“研究证明”不能改成编造的实名来源；不能把被归因的说法变成自己的确定断言。
- 标点按中文用途保持一致；代码、JSON、路径和原文引语使用其原有格式。

## 重复动作与持续状态

“先前发生了什么”和“现在仍怎样”可能是两项信息。重复谓语显得生硬时，换承接方式，不直接删掉时间层次。

原文：门牌上少了一颗螺丝。我找了一圈，没找到，到今天这个问题也没解决。门牌仍歪着，我暂时没动它。

可改：门牌上少了一颗螺丝。我找了一圈也没找到，到今天还缺着。门牌仍歪着，我暂时没动它。

这里“还缺着”有缺螺丝、未找到和问题未解决作依据。若原文只说没找到螺丝，却可能另换了一颗，就不能自行断定至今仍缺。涉及未知现状时保留原文的不确定表达；技术对象的重复也可能用于稳定指称，不必换成近义词。

## 技术标识与动作

技术说明区分标识的值与呈现方式。含义确定的状态码、版本号和单位，可以按目标读者熟悉的写法呈现，例如正文中的“状态码四二九”可写成“状态码429”；不能因此改变值、补造协议背景，或统一把所有中文数词改为数字。代码块、引号内的实际字符串、字段名和命令仍原样保留。

精简操作说明时保住实际动作。材料要求等待后重试，就不能只留下“参考某字段”，让读者自己猜还需等待。条件、动作与动作所依据的字段可放在一起；材料没有规定怎样处理时，不添加推测的步骤。

## 处理规则冲突

- 简洁与解释冲突时，删除无效复述，保留读者理解所需的关系与背景。
- 直接与准确冲突时，保留真实限定，去掉重复的缓冲表达。
- 个性与用途冲突时，按作者选择和目标文体决定，不能统一改成口语或客服腔。
- 节奏与含义冲突时，先保留关系；不靠碎句、标点禁令或凑项制造变化。
- 发现问题与最小修改冲突时，只改影响任务的地方，不强求全文重写。
