# 段落结构与解释

在长文套模版、观点迟到、概念跳跃或压缩表达妨碍理解时使用。目标是让读者沿着当前问题往下读，不为每篇文字安排相同的结构。

## 先看信息怎样推进

用材料中的内容辨认主张、依据、解释、条件、例子和行动。某些段落只是在预告、复述或抬高语气时，可以删并；两个段落分别提供不同依据时，即使句式相似也不能合并丢失。

先给结论适合问答、故障说明、操作建议和许多报告。叙事、论证铺垫和需要保密顺序的文体，按作者意图处理。不要把所有长文重排成“问题—原因—建议”三段。

## 常见断点

| 断点 | 修改方法 | 含义边界 |
| --- | --- | --- |
| 标题后又预告标题 | 直接接定义、证据或限制 | 标题中的词重复出现不等于重复信息 |
| 一段说了很多却没有主张 | 用材料已经支持的判断作中心，其余内容按作用排列 | 没有依据时不能替作者做决定 |
| 原因与结论隔得远 | 把解释移到它要支持的判断旁边 | 不把先后、并列或相关改成因果 |
| 术语先于概念 | 先用材料说明它解决的具体问题，再引入或解释术语 | 专业读者不需要从基础重新讲起 |
| 主语或指代不清 | 只在误认、回读或搭配错位处写明已知对象，顺畅省略可保留 | 不猜未知施事者、缺失指代或未给出的身份 |
| 名词串压缩了过程 | 展开动作、对象和条件，让读者看见关系 | 不增加材料没有的实现步骤 |
| 句子都短却断裂 | 恢复确有作用的顺序、转折、条件和因果连接 | 不为了“自然”引入新的关系 |
| 结尾反复升华 | 结束在材料已有的结论、状态或下一步 | 有用总结、情绪与有意留白可以保留 |

## 不用字数替代理解

省去可从上下文恢复的重复词，与省去读者尚未知道的必要解释，是两件事。一个句子引入多个陌生概念时，可以拆开或展开；已有因果、条件和比较对象不因追求短句而删除。

仅润色不增加例子、背景或机制。只有用户明确授权补充讲解、扩写或创作时，才在相应范围使用例子或假设情境。比喻不能代替实际机制，也不能让读者把类比细节误认为事实。

## 有意的含蓄

个人文章可以直接说态度而不拔高成普遍道理。文学叙事可以通过行为、对话和情境留下判断空间，不必补上人物的最终成长、每个意象的寓意或完整因果。原文已经有明确解释时，也不为了制造留白删改作者意图。

修改后检查相邻段落：读者知道本段对象是什么、为何在此出现、与前段是什么关系。解释缺口无法用材料补齐时，保留原意或简短指出缺口，不写一段空泛过渡来掩盖。

显化关系的前提是它已经在原文建立，或能从局部上下文唯一还原。更合理、更符合常识或更方便操作，都不足以支持一个新的原因、结果或步骤。

## 安排与边界放在一起

当读者需要根据文字安排动作或形成预期时，把具体安排及其适用范围、例外、尚未确定的部分放近。不要在承诺和限制之间插入一段评价或动机，使读者读到后面才发现前面的安排有条件。需要交代的理由可以放在相邻的其他位置，顺序服从这次沟通用途。

日期、数量或结论在后文再次被指代时，保留它原有的性质，例如“预计到货时间”不能因重排变得像确定的交付承诺。上下文已经明确时不必句句重复限定；会造成误读的位置仍应写清。
